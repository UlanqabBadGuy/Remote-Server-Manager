# Checklist

- [x] 项目脚手架：Tauri v2 + React + TypeScript 项目可正常编译和运行
- [x] 连接配置 CRUD：可创建、查看、编辑、删除连接配置，数据持久化到文件
- [x] 连接分组：支持分组管理，连接列表按分组折叠展示
- [x] 密码认证：使用密码可成功连接远程 SSH 服务器
- [x] 私钥认证：使用 SSH 私钥文件可成功连接远程服务器
- [x] 连接失败处理：网络不通或认证失败时显示明确错误提示
- [x] 凭证安全存储：密码通过系统密钥链加密存储，配置文件中不含明文密码
- [x] 远程目录浏览：连接后可浏览远程目录树，展开/折叠子目录
- [x] 文件上传：可将本地文件上传到远程服务器指定目录
- [x] 文件下载：可将远程文件下载到本地
- [x] 文件删除：可在远程文件浏览器中删除文件和目录
- [x] 文件重命名：可重命名远程文件
- [x] 新建远程目录：可在远程服务器上创建新目录
- [x] 内置终端：可打开 SSH 终端并执行命令
- [x] 终端多标签页：支持多个终端会话以标签页形式管理
- [x] 终端复制粘贴：Ctrl+Shift+C/V 快捷键正常工作
- [x] 终端自适应大小：调整窗口时终端行列数自动适配
- [x] 快速连接：支持临时连接，无需保存配置
- [x] 连接导入导出：支持将连接配置导出为文件，也可从文件导入
- [x] 主题切换：支持亮色和暗色主题切换
- [x] Linux 平台编译运行：在 Linux 上编译并运行，功能正常
- [x] Windows 平台编译运行：跨平台编译配置就绪（Tauri bundle 目标已配置）
- [x] macOS 平台编译运行：跨平台编译配置就绪（Tauri bundle 目标已配置）
