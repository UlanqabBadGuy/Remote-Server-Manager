# 跨平台远程连接管理器 规范

## Why
需要一个跨平台（Linux、Windows、macOS）的远程连接管理工具，支持存储和管理多个 SSH 连接、可视化浏览远程文件目录、以及内置命令行终端，方便开发者和运维人员高效管理远程服务器。

## What Changes
- 新建 Tauri v2 桌面应用项目，使用 Rust 后端 + React 前端
- 实现 SSH 连接管理（增删改查、分组、快速连接）
- 实现远程文件浏览器（目录树、文件操作）
- 实现内置终端（基于 xterm.js 的 SSH 终端）
- 实现凭证安全存储（系统原生密钥链）
- 实现多标签页会话管理
- **BREAKING**: 无（全新项目）

## Impact
- Affected specs: 无（全新项目）
- Affected code: 整个项目从零构建

## ADDED Requirements

### Requirement: 连接配置管理
系统 SHALL 提供 SSH 连接配置的完整 CRUD 操作，包括连接名称、主机地址、端口、用户名、认证方式（密码/密钥）、分组标签。

#### Scenario: 创建新连接
- **WHEN** 用户填写连接信息（主机、端口、用户名、密码或密钥路径）并保存
- **THEN** 连接信息被加密存储，并显示在连接列表中

#### Scenario: 编辑已有连接
- **WHEN** 用户修改某个连接的配置信息并保存
- **THEN** 更新后的信息被持久化，且不影响当前已建立的会话

#### Scenario: 删除连接
- **WHEN** 用户删除一个连接
- **THEN** 该连接配置被移除，如果该连接有活跃会话则提示用户

#### Scenario: 连接分组管理
- **WHEN** 用户创建分组并将连接归入不同分组
- **THEN** 连接列表按分组展示，支持折叠/展开

### Requirement: SSH 连接与认证
系统 SHALL 支持通过密码和 SSH 私钥两种方式认证连接到远程服务器。

#### Scenario: 密码认证连接
- **WHEN** 用户使用密码认证方式连接远程主机
- **THEN** 系统建立 SSH 连接并返回连接状态

#### Scenario: 私钥认证连接
- **WHEN** 用户选择 SSH 私钥文件并输入密钥密码（如有）
- **THEN** 系统使用私钥进行认证并建立连接

#### Scenario: 连接失败处理
- **WHEN** SSH 连接由于网络问题、认证失败或超时无法建立
- **THEN** 系统显示明确的错误信息

### Requirement: 远程文件浏览器
系统 SHALL 提供可视化的远程文件目录浏览功能，支持目录树导航和基本文件操作。

#### Scenario: 浏览远程目录
- **WHEN** 用户连接到远程服务器后打开文件浏览器
- **THEN** 显示远程服务器的目录树结构，支持展开/折叠子目录

#### Scenario: 文件上传
- **WHEN** 用户选择本地文件上传到远程目录
- **THEN** 文件通过 SFTP 传输到远程服务器，完成后刷新目录视图

#### Scenario: 文件下载
- **WHEN** 用户在远程文件浏览器中选择文件并下载
- **THEN** 文件通过 SFTP 下载到本地指定目录

#### Scenario: 文件删除
- **WHEN** 用户在远程文件浏览器中删除文件或目录
- **THEN** 弹出确认对话框，确认后执行删除操作并刷新视图

#### Scenario: 文件重命名
- **WHEN** 用户在远程文件浏览器中重命名文件
- **THEN** 远程文件被重命名，目录视图同步更新

### Requirement: 内置命令行终端
系统 SHALL 提供内置的 SSH 终端，支持完整的终端交互。

#### Scenario: 打开终端会话
- **WHEN** 用户双击连接或点击"打开终端"
- **THEN** 系统在新标签页中打开 SSH 终端，用户可直接输入命令

#### Scenario: 终端多标签页
- **WHEN** 用户打开多个终端会话
- **THEN** 每个会话以独立标签页形式展示，支持切换和关闭

#### Scenario: 终端复制粘贴
- **WHEN** 用户在终端中使用键盘快捷键复制（Ctrl+Shift+C）和粘贴（Ctrl+Shift+V）
- **THEN** 终端正确响应复制粘贴操作

#### Scenario: 终端自适应大小
- **WHEN** 用户调整窗口大小
- **THEN** 终端自动调整行列数，并通知远程服务器

### Requirement: 跨平台支持
系统 SHALL 在 Linux、Windows 和 macOS 上均可编译和运行，功能一致。

#### Scenario: Linux 平台运行
- **WHEN** 在 Linux 系统上编译并运行应用
- **THEN** 所有核心功能正常可用

#### Scenario: Windows 平台运行
- **WHEN** 在 Windows 系统上编译并运行应用
- **THEN** 所有核心功能正常可用

#### Scenario: macOS 平台运行
- **WHEN** 在 macOS 系统上编译并运行应用
- **THEN** 所有核心功能正常可用

### Requirement: 凭证安全存储
系统 SHALL 使用操作系统原生密钥链安全存储密码和私钥密码。

#### Scenario: 存储密码
- **WHEN** 用户保存连接时包含密码
- **THEN** 密码通过系统密钥链加密存储，不在配置文件中明文保存

#### Scenario: 读取密码
- **WHEN** 系统需要建立连接时
- **THEN** 从系统密钥链中读取对应的凭证进行认证
